# Hero asset decisions — P2 local preview

The immutable original is `source/original.jpg`. See `source/provenance.json` for origin/checksum and unresolved rights. No location or author identity is inferred from Pinterest tags. This asset set is a local preview; rights remain a release gate for deployment/contest submission.

`work/sky-generated.png` is a synthetic sky continuation created with image_gen using the selected photograph. Its altered sky/signature is not presented as original photography: the original sky pixels are rendered above it using an original-source mask. The generated plate appears only in the gaps during the reveal.

The prototype chooses four overlapping native polygon silhouettes sharing the original photo `currentSrc` and an intrinsic 2048x1365 coordinate frame. The original terrain is not redrawn, upscaled, or exported repeatedly as four lossy images. This refines the planned RGBA-file pipeline: transparent cutouts are composed by browser clip paths, avoiding repeated transfers and preserving source detail. Each silhouette extends to the canvas floor. The first disjoint-band prototype failed visual review because movement exposed straight lower edges and gold sky gaps; overlap and smaller displacement remove those strip edges. `scripts/hero/verify-assets.mjs` checks the contours remain nested without crossing. Final idle uses the static poster and cancels running animations.

These are bounded photo-depth silhouettes, not independent recovered 3D mountains. Hidden terrain cannot be reconstructed from this photograph. Lower terrain also exists in the far silhouette, so the reveal is a small staggered composition with overlapping photo content rather than a claim that every physical mountain was separated perfectly. Browser midpoint/end frames remain the quality gate.

Responsive encoding is handled by Next Image with explicit sizes and quality allowlist. Raw public files are inputs to optimization. Browser tests must count the actual selected source and generated plate bytes, including both resources, and report the four compositing surfaces separately from network bytes.

The initial q90 pilot selected a 1920px WebP of 327532 bytes and had a 3072ms LCP in the specified slow-mobile lab profile. A same-resolution q75 comparison was 161584 bytes and was visually reviewed against q90; q75 is the shipped poster setting. This preserves spatial resolution while accepting lossy encoder differences. The original JPEG remains immutable; no claim of lossless delivered compression or 4K detail is made.

Art direction: centered editorial title, gold sunset/forest/ivory, source focal point (50%,55%), two CTA, intro2.8s. Text is always visible. Motion is small, staggered, finite. Each tab/session plays once; explicit replay is available. Reduced motion, missing layers, timeout and no-JS retain poster/content. Implementer reviewed first-paint/midpoint/end screenshots and a rendered screencast; final independent visual approval remains pending. Overlapping photo silhouettes are an approximation, not recovered hidden terrain. No physical-device FPS is claimed.

All display headings, including the hero, use the shared Times New Roman serif token on the tested Windows browsers. Georgia lacked some Vietnamese glyphs and mixed a fallback font inside words. The shared token removes that observed spacing defect across public pages and preserves two rendered typography families without adding a font download. Actual Android/iOS font mapping still needs device review.

Benchmark-only true 3D geometry lives in scripts/hero/terrain-spike.mjs, outside production imports. It is a procedural lower-bound comparator (geometry, no texture or R3F/Drei overhead), not a production terrain model. True 3D production decision is pending Paw and measured physical-mobile evidence.
